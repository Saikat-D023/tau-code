How it works

Ask. Recall. Approve.

Type a request in your terminal. tau pulls in the memory that matters, plans with your model, and stops for a yes before it touches anything.

  • Any provider. Log in to OpenAI with your ChatGPT account, or paste an Anthropic API key. Swap models mid-session with /model.
  • A permission gate. Every write, edit and shell command asks first. Reads run freely.
  • A live dashboard. Reasoning, memory, tool calls, traces and cost at localhost:7777.

Design

Fully local. Less on purpose.

Everything tau does happens on your machine where you can see it. Each of these choices has an ADR in docs/adr/.

No cloud sandbox

Tools run directly on your machine, which is why every write, edit and shell command asks you first.

No hosted service

There's no account to create and no server of ours between you and the model. You bring your own provider.

No spoofed logins

Claude uses a real API key. Logging in with a Pro/Max subscription would mean impersonating another product, and that gets accounts banned.

Install

Zero to a working agent in four steps.

taucode runs on Bun. You need bun, git, and an OpenAI account or Anthropic API key.

1Install Bun

Skip this if bun --version already works.

macOS / Linux
curl -fsSL https://bun.sh/install | bash
Windows
powershell -c "irm bun.sh/install.ps1 | iex"
2Clone and install

Pull the repo and install its dependencies.

git clone https://github.com/Saikat-D023/tau-code.git
cd tau-code && bun install
3Connect a provider

OpenAI uses a browser login against your ChatGPT/Codex account. Claude takes an API key. Credentials are saved to ~/.taucode/auth.json, outside the repo.

bun run auth
4Start tau

Opens the chat loop in your terminal and the live dashboard at localhost:7777.

bun start

Commands

Everything you can type, run or configure.

/modelOpens an interactive picker for models on your current provider.
/model <name>Sets the model directly on your current provider.
/authLogs in to or switches provider (OpenAI OAuth or Claude API key) without leaving the session.
exit · quitEnds the session. Ctrl+D also works.
anything elseSent to the agent as a turn. Tool calls print inline as ↳ tool {args}.
bun startStarts the CLI and the dashboard on :7777.
bun run authRuns the provider login flow before you start.
bun run evalRuns the deterministic eval suite (bun test assertions).
bun run eval:judgeLLM-as-judge scoring of agent responses.
bun run eval:gateFails when eval scores drop below TAU_EVAL_THRESHOLD. Meant for CI.
bun run tracePoints you at the JSONL traces in .tau/traces/.
read_fileno promptReads files in your project.
write_fileasks firstCreates or overwrites a file.
edit_fileasks firstMakes targeted in-place edits.
bashasks firstRuns a shell command directly on your machine.
search_webLooks things up on the web.
manage_memoryasks firstAdds, updates or removes project Facts.
create_skillasks firstSaves a reusable procedure with trigger keywords.
update_soulasks firstEdits .tau/SOUL.md, the project's standing persona and preferences.
OPENAI_API_KEYOptional OpenAI key, used instead of the OAuth login.
ANTHROPIC_API_KEYYour Anthropic key for the Claude provider.
TAU_GRAPH_WORKFLOWS=1Turns on the Triage Graph: greetings get a quick reply, and everything else runs the full loop. If the graph errors, tau falls back to the plain loop.
TAU_DIROverrides where project state (.tau/) lives.
TAU_GATE_MODELModel used by the retrieval gate.
TAU_JUDGE_MODEL · TAU_EVAL_THRESHOLDJudge model and pass threshold for evals.
